==================================================

Support optional query params on our backend route where sensible:

- lomin
- lamax
- lomax

OpenSky supports querying by bounding box using:
- lamin = lower latitude
- lomin = lower longitude
- lamax = upper latitude
- lomax = upper longitude

Default bounding box should be suitable for a London / Heathrow view if no bounds are provided, for example roughly:
- lamin = 51.2
- lomin = -0.9
- lamax = 51.8
- lomax = 0.3

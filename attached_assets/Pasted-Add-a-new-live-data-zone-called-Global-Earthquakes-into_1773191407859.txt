5. FIELD MAPPING REQUIREMENTS
==================================================

Map common USGS GeoJSON fields carefully and defensively.

At minimum support:
- feature.id -> id
- properties.place -> place
- properties.mag -> magnitude
- properties.time -> time
- properties.updated -> updated
- properties.url -> url
- geometry.coordinates[0] -> longitude
- geometry.coordinates[1] -> latitude
- geometry.coordinates[2] -> depthKm
- properties.tsunami -> tsunami (boolean)
- properties.felt -> feltReports
- properties.alert -> alert

Convert epoch millisecond values from USGS into ISO strings for frontend use.

Guard against:
- missing geometry
- null magnitude
- missing place
- missing coordinates
- partial features

Add comments in the service file noting where payload mappings may need adjustment if the upstream schema changes.

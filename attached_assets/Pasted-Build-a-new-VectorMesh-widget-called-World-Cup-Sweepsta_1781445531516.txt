Build a new VectorMesh widget called World Cup Sweepstake Wall.

Purpose:
Create a fun, bright, informative internal staff engagement widget for the football World Cup. Staff members are randomly assigned to World Cup teams. As teams are knocked out, the assigned staff member is also knocked out. The person assigned to the winning team becomes the overall sweepstake winner.

Important:
Do not remove or break existing VectorMesh functionality.
Do not use protected FIFA branding, logos, mascots or official artwork unless supplied/licensed.
Use neutral naming such as “World Football Sweepstake” or “Tournament Sweepstake Wall”.

Data sources:
Create a provider abstraction for live tournament data.
Support:
- Sportmonks
- API-Football / API-Sports
- football-data.org
- manual data fallback

Store API keys only in environment variables.
Do not expose API keys to the frontend.
Fetch data server-side and cache in the database.
Displays must read cached data only.

Data required:
- teams
- groups
- fixtures
- match status
- results
- group tables
- knockout status
- eliminated teams
- tournament winner
- team flags/badges where legally usable
- fallback to ISO country flags or uploaded graphics

Admin UI:
Add a World Cup / Sweepstake admin section.

User must be able to:
- choose data provider
- configure API key via environment variable guidance
- manually sync tournament data
- view teams, fixtures, results and standings
- add staff names manually
- import staff names from CSV
- randomly assign staff to teams
- support multiple staff per team if staff count exceeds team count
- reset assignments with confirmation
- manually override team assignments
- mark teams eliminated manually if API data is unavailable
- export sweepstake assignments as CSV

Sweepstake assignment logic:
- Randomly assign teams fairly.
- If staff count is lower than team count, leave some teams unassigned.
- If staff count is higher than team count, distribute evenly across teams.
- Do not assign the same person twice.
- Include a dramatic reveal mode showing one staff member and team at a time.

Elimination logic:
- During group stage, use standings/qualification rules where available.
- During knockout stage, eliminate losing teams automatically after final result.
- When a team is eliminated, update assigned staff status to eliminated.
- When the tournament winner is known, mark assigned staff as winner.

Design:
Make it fun, bright and energetic.
Use bold typography, colourful team cards, flag graphics and animated transitions.
Suitable for office screens, reception screens, portrait totems and landscape displays.
Prioritise readability from distance.
Do not cram too much text onto one screen.

Responsive behaviour:
Auto-select layout:
- Landscape: multi-card dashboard
- Portrait/totem: large single-card rotation
- Ultrawide: fixtures + standings + sweepstake strip
- Small zones: next match or current sweepstake highlight only

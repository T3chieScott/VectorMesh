9. AeroDataBox field mapping rules
Map AeroDataBox fields carefully and defensively.

Important:
- Do not assume old field names like actualTimeUtc
- Use the current schema fields such as scheduledTime and revisedTime where applicable

- If actual time is not available, leave actualTime as null
- Preserve raw status in rawStatus

Please add comments in the service file highlighting where payload mappings may need future adjustment if AeroDataBox changes.

# VectorMesh

VectorMesh is an onsite display management platform for conference and exhibition centres. It manages content across meeting rooms, public displays, and large LED video walls, with support for scheduled programming, live overrides, zone-based layouts, real-time diagnostics, and Raspberry Pi-based display nodes.
